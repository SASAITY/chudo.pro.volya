# Длить волю · chudo.pro

Лёгкое приложение с двумя пространствами: «Космос» и «Сфера». Подготовлено для мобильных браузеров и Telegram Mini Apps.

## Сфера воли

Человек парит в пространстве и растит радужную звезду из центра груди. Каждый сохранённый акт увеличивает её размер и насыщенность. Лучи и блики этапов продолжают исходить из человека. «В центр» показывает человека внутри поля, «Вся сфера» отдаляет камеру до обзора всей звезды. Оба пространства используют общую историю актов и настройки лучей.

Поверхность звезды — анимированная объёмная плазма без горизонтальных полос, с сияющей короной. Палитра и узор вынесены в отдельный модуль для последующей настройки; пользовательского редактора сферы пока нет. Размер звезды продолжает расти после семи актов, яркость плавно приближается к пределу.

## Запуск

```sh
npm ci
npm run build
npm start
```

Статическая сборка находится в `dist`. Vercel использует настройки `vercel.json`.

## Данные

Акты хранятся в localStorage текущего браузера. Удаление луча скрывает его акты из истории и останавливает его текущий таймер; действие можно отменить кнопкой «Вернуть». Облачной синхронизации нет. Данные с localhost автоматически не переносятся на опубликованный домен.

## Мобильная графика

30 кадров в секунду и ограниченная плотность рендеринга на мобильных устройствах. Сглаженные облегчённые сферы, повторное использование текстур сияния, отложенная генерация текстур спутников. Рендеринг приостанавливается в скрытой вкладке. Поля ввода и диалоги учитывают экранную клавиатуру. Анимация учитывает настройку сокращения движения.

Сияние и размер человека достигают максимума на 7 актах. Повторные нажатия приближают камеру к надписи на кепке.
